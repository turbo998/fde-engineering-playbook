# FDE Engineering Playbook

Evidence-led research into AI-assisted engineering workflows, with an anonymous travel-operations case study and reproducible comparative experiments.

The planned comparison covers HVE, Superpowers, gstack, and a no-method-package baseline. Spec Kit and OpenSpec are supplementary research subjects.

## Status

Repository initialized. Research, implementation, and benchmark infrastructure are in progress. No experimental results are available yet.

Measured development and real-model runtime trials require a confirmed model configuration, verified isolation and compatibility, and approved usage limits.

## Publication boundary

This repository will contain original documentation and implementations, synthetic business fixtures, and sanitized results only. It does not contain customer systems, customer data, proprietary source materials, credentials, or raw model transcripts.
